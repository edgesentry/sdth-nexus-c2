# Shared Schemas & Data Types

**Status:** Phase 2 freeze · Definitive data structures for the C2 ontology, courses of action, cryptographic tokens, findings, and recipient acknowledgments.

These schemas underpin both the **[C2 REST API](rest.md)** and the **[Upstream Ingress](ingress.md)** pipeline. For frontend TypeScript bindings, refer to [`archview-types.ts`](archview-types.ts).

---

## 1. `CourseOfAction` (`coa`)

The canonical representation of tactical intent proposed by the C2 platform.

| Field | Type | Notes |
|-------|------|--------|
| `coa_id` | string (uuid) | Client must echo into approve / ack |
| `tier` | `0` \| `1` \| `2` | Tier-0 auto-approve; Tier-1 single operator; Tier-2 dual-key |
| `target_entity_id` | string | Track or target identifier |
| `target_coordinates` | `[lat, lon]` | Intercept or patrol coordinates |
| `intent` | string | e.g. `GNSS_DENIAL_AND_GBAD_CUE` (Pillar 1); `OFFSHORE_INTERCEPT_RF_SOFTKILL` (Pillar 2); `APPROACH_PATROL` (Pillar 3) |
| `timeout_seconds` | number | HITL approval window (typically 30s) |
| `confidence` | number | Normalised confidence (0.0 to 1.0) |
| `corroborating_sources` | string[] | Corroborating sensor source IDs |
| `raw_input_digest` | string | SHA-256 hash of originating scenario input |
| `speed_kt` | number \| null | Interlock / kinematic parameter |
| `pre_conditions` | object | Pre-execution safety invariants |
| `post_conditions` | object | Desired terminal state |
| `invariants` | object | Guardrail constraints (e.g. CNI fallout geofence) |
| `metadata` | object | Opaque operational metadata |

## 2. `DecisionToken` (`token`)

The cryptographic authorization seal issued strictly by the Nexus Gate upon operator approval.

| Field | Type | Notes |
|-------|------|--------|
| `token_id` | string (uuid) | Unique identifier for the sealed token |
| `coa_id` | string (uuid) | Matches the approved Course of Action |
| `verdict` | string | `APPROVED` / `REJECTED_FAST` / `REJECTED_OPERATOR` / `TIMEOUT` |
| `issued_at` | ISO-8601 | UTC timestamp of decision |
| `operator_id` | string \| null | Authorizing commander/operator identifier |
| `reason` | string \| null | Operational justification or guardrail lockout code |
| `digest` | string | SHA-256 cryptographic seal; empty only before seal |

> [!IMPORTANT]
> The client UI or edge effector never issues or seals tokens independently. Only Core `POST /api/gate/approve` has authority to issue a valid `DecisionToken`.

## 3. `Finding` (proposal `finding`)

Probabilistic or deterministic threat interpretation generated by LLM reasoning or heuristic rule engines.

| Field | Type | Notes |
|-------|------|--------|
| `scenario_id` | string | e.g. `S2_osint_swarm`, `S1_trojan`, `S3_sar_ais` |
| `track_id` | string | Associated track identifier |
| `threat_class` | string | High-level classification (e.g. `ATTRITABLE_SWARM_INCURSION`) |
| `warning_minutes_est` | number | Estimated time to impact / boundary cross |
| `mismatch_m` | number | Spatial divergence between sensor modalities |
| `confidence` | number | Overall finding confidence (0.0 to 1.0) |
| `picture_summary` | string | Human-readable synthesis of sensor picture |
| `adversarial_hypothesis` | string | Working hypothesis of adversary tactics |
| `spoof_sources` | string[] | Sensors identified as spoofed/divergent |
| `approach_sources` | string[] | Sensors tracking the primary approach |
| `other_sources` | string[] | Additional background or secondary sensors |
| `message` | string | Primary warning / rationale string |
| `amber_alert` | string \| null | Contradiction classification tag (e.g. `OSINT_PASSENGER_VS_RADAR_SILENCE`) |
| `source_breakdown` | object | Modality $\to$ claim dictionary (e.g. `{"social": ..., "radar": ...}`) |

## 4. Track (`ontology.tracks[]`)

Fused or segregated track entity managed in the Nexus `SpatialEntityGraph`.

| Field | Type | Notes |
|-------|------|--------|
| `track_id` | string | Primary track identifier |
| `latitude` | number | WGS-84 latitude |
| `longitude` | number | WGS-84 longitude |
| `speed_mps` | number | Estimated speed in meters/second |
| `confidence` | number | Aggregate track confidence |
| `source_ids` | string[] | All contributing sensor source IDs |
| `modalities` | string[] | Observed modalities (e.g. `social`, `radar`, `optical`, `ais`, `space_sar`) |
| `updated_at` | ISO-8601 \| null | Timestamp of latest state update |
| `attributes` | object | Opaque attributes dictionary |

---

## 5. Observation (`ontology.observations[]`)

Atomic sensor measurement or intelligence report ingested into the system.

| Field | Type | Notes |
|-------|------|--------|
| `observation_id` | string | Unique observation identifier |
| `source_id` | string | Originating sensor ID |
| `entity_hint` | string | Target hint / classification tag |
| `latitude` | number | WGS-84 latitude |
| `longitude` | number | WGS-84 longitude |
| `altitude_m` | number \| null | Altitude in meters above sea level |
| `speed_mps` | number | Speed in meters/second |
| `heading_deg` | number \| null | Heading in degrees (0–360) |
| `confidence` | number | Sensor-reported confidence |
| `observed_at` | ISO-8601 | Timestamp of physical measurement |
| `modality` | string | Sensor modality (`radar`, `ais`, `optical`, `social`, `space_sar`, `adsb`, `acoustic`) |
| `attributes` | object | Sensor-specific metadata |
| `raw_digest` | string | SHA-256 digest of original raw event payload |

---

## 6. AckRecord (`ack` on recipient response)

Closed-loop tasking acknowledgment returned by the field effector unit.

| Field | Type | Notes |
|-------|------|--------|
| `ack_id` | string (uuid) | Unique acknowledgment record ID |
| `coa_id` | string (uuid) | Target Course of Action ID |
| `unit_id` | string | Assigned field effector ID (e.g. `CUE-NODE-01`, `USV-02`) |
| `status` | string | Tasking state (e.g. `ACKED`, `REJECTED`, `EXECUTING`) |
| `message` | string | Status explanation from recipient |
| `telemetry` | object | Field unit telemetry snapshot |
| `signature` | string | Client-supplied or server-sealed SHA-256 signature |
| `token_digest` | string | Verified SHA-256 seal from the `DecisionToken` |
| `acked_at` | ISO-8601 | UTC timestamp of acknowledgment |
